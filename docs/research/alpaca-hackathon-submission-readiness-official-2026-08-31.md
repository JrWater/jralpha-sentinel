## Event-specific mandatory conditions — verified

Alpaca's official event announcement requires:

1. A dedicated competition paper account, one per email.
2. A competition-account starting balance of USD 100,000.
3. A one-page write-up covering the AI logic, risk gates, and Alpaca
   infrastructure implementation.
4. Options trading in every strategy.
5. Alpaca Trading API plus either Alpaca MCP Server or Alpaca CLI.

The same announcement says judging is based on P&L and creativity or
engagement. The event page describes the intended build as autonomous agents
or trading apps using Alpaca's Trading API, MCP server, and CLI.

Sources: [Alpaca official company announcement](https://www.linkedin.com/company/alpacamarkets/),
[LabLab event page](https://lablab.ai/ai-hackathons/alpaca-ai-trading-agents-hackathon).

## LabLab project-submission package — verified platform requirements

LabLab's own submission guide describes these form stages:

| Stage | Required/validated information |
| --- | --- |
| Project information | title (maximum 50 characters), short description (maximum 255 characters), long description (minimum 100 words), main track, technologies |
| Media | recommended 16:9 cover image; video-presentation link, under 300 MB and no longer than five minutes |
| Technical details | public GitHub repository, demo application platform, direct live demo/application URL, optional additional information |
| Finalization | use the form's **Submit** control |

LabLab's FAQ independently says a complete package needs a working prototype
available online, a video presentation, and a pitch deck. Its AI-hackathon
guide additionally specifies a pitch video of no more than five minutes in
MP4 format, a PDF slide deck, and a public GitHub repository.

Sources: [LabLab submission guidelines](https://lablab.ai/ai-articles/hackathon-guidelines),
[LabLab platform guide](https://lablab.ai/guide),
[LabLab AI hackathons guide](https://lablab.ai/guide/ai-hackathons).

## Submission procedure — verified platform flow

1. Sign in to LabLab and ensure every participant has enrolled; LabLab says
   every member, including a solo participant, must register independently.
2. Create or join a team. LabLab says team membership is required even for a
   solo participant.
3. On the event page, select **Submit project**.
4. Complete project information, media, and technical-details stages above.
5. Verify the generated project page and select **Submit** before the deadline.

Sources: [LabLab platform guide](https://lablab.ai/guide),
[LabLab submission guidelines](https://lablab.ai/ai-articles/hackathon-guidelines).
